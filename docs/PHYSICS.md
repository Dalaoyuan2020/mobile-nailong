# PHYSICS · 会不会倒

输入数字见 [SPEC.md](SPEC.md) 的质量预算（合计 19 kg，重心离地约 186 mm）。
以下是粗估，到货后用实测质量重算。

## 1. 整车推着会不会翻

整车翻倒要的加速度 ≈ g × 半轮距 / 重心高。

| 方向 | 半距 | 翻倒要的加速度 |
|---|---|---|
| 左右（半轮距 200 mm） | 200 | 约 1.1 g |
| 前后（半轴距 270 mm） | 270 | 约 1.5 g |

我们限加速 0.25 m/s²（约 0.03 g），差了几十倍。**正常开，整车不会翻。**
立牌虽然高，但只有 1.5 kg；8 kg 配重在箱底，重心压得很低。

## 2. 真正的风险

1. **风**。立牌是一面 0.8 m² 的帆。粗估（平板风阻系数 1.2，风力作用点在板中 1.14 m 高）：
   - 迎面风（推前后方向）约 **8.8 m/s** 会推翻，大约 5 级风。
   - 如果不放 8 kg 配重，约 **6.7 m/s** 就翻，大约 4 级风。
   - 结论：室内随便走；户外有风别开，配重一定要放。
2. **立牌自己晃**。KT 板 1.6 m 高，底下猛加速或急刹，顶端会甩。整车没翻，但板可能弯折、绑带松脱。这就是 L4 要管的。
3. **急刹 / 急转**。「倾斜就急停倒车」这类规则本身会甩板，所以急停也要按斜坡减速。
4. **窄底盘**。现成 500×300 平台轮距约 300 mm 左右，左右翻倒余量降到约 0.8 g，仍然够，但风的余量也跟着变小。

## 3. 稳走策略（L4 实现）

| 手段 | 做法 |
|---|---|
| 限加速 | 摇杆 / 跟随给出的目标速度，先过加速上限再给电机 |
| 姿态自适应 | IMU 测立牌前后倾角和角速度；晃得越厉害，加速上限按比例降低；平稳几秒后慢慢恢复 |
| 转弯限速 | 侧向加速 = 速度² / 转弯半径，超上限就减速或放大转弯半径 |
| 软急停 | 倾角超阈值 → 按斜坡减速到零，不硬刹，不倒车 |
| 前方障碍 | 超声波：远了减速，近了停 |
| 台阶 / 坑 | 前缘朝下 ToF 测到地面突然变远 → 停 |

阈值（倾角多少算晃、加速上限降多少）先不拍，到货后实测立牌晃动再定，写回 SPEC。

## 4. 测试顺序

1. 底盘空走
2. 底盘 + 箱 + 8 kg 配重
3. 再绑 1.6 m 立牌
4. 急推摇杆、急停、慢转、过门槛、侧推立牌顶端
5. 同样动作，关掉 / 打开 L4 各录一段，对比立牌顶端晃动（Demo 素材）
