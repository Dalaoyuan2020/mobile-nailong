# 重心与防倾

> 历史横放计算：不适用于当前竖立箱体，不能据此判断当前装配稳定性；当前几何见 [当前 prompt](PROMPT_STAND_HANDLE.md)，稳定性需按新姿态与实测质量重算。

立牌 **1.6 m**（从箱顶算）。箱 26 寸躺平。

## 待机质量

| | kg | 质心高 mm（离地） |
|---|---|---|
| 底盘 | 3 | 50 |
| 箱 | 5 | 180 |
| 配重 | 8 | 80 |
| 立牌 1.6 m | 1.5 | 360+800=1160 |
| 合计 | 17.5 | **约 220 mm** |

板若达 2.5 kg，整机重心升到约 280 mm。板必须轻。

## 静止

半轮距按 200 mm算：
侧向允许加速 ≈ g × 200 / 220 ≈ 0.9 g。数字很宽。
真正会倒的是：原地甩尾、板枪转弯、侧风、有人撕板。

## 硬限制

- 速度 ≤ 0.30 m/s
- 加速 ≤ 0.25 m/s²
- 转弯半径 ≥ 1.5 m（不许原地转）
- 板背 IMU >8° / 200 ms → 断电机
- 侧推 2 N，倾 < 5°

## 测试顺序

1. 底盘空走
2. 底盘 + 箱 + 8 kg
3. 再绑 1.6 m 板
4. 慢转、急停、侧推
