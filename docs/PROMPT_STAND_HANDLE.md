# PROMPT · 竖立行李箱背负奶龙立牌

从下面分隔线复制到文末，整块贴给本地模型。

---

你在仓库 mobile-nailong 修改现有模型。用户已用照片纠正设计：正常竖立的行李箱，轮子在底下，拉杆向上；奶龙立牌贴在箱子的大面，箱子藏在板后。以本段最新要求覆盖旧“横放箱子、矩形板叠箱顶、三绑带”的要求。

先把大概形状建对，再列材料清单、做运动与稳定性仿真，并说明功能怎么实现；固定方式尚未定型，不围绕绑带细节浪费时间。

1. 坐标 +X 正脸/+Y 左右/+Z 向上，地面Z0。沿用 cad/case26/ 原壳体，通过 cad/handle/case_pose.py 旋转平移；竖箱范围 X±145、Y±235、Z70…790 mm，高720×宽470×深290。仅总装副本开拉杆导座槽。
2. 当前四个普通箱轮Ø50，中心X±105、Y±200，轮底落地，左右距400、前后距210。旧540是横放方案孔距，不套到竖箱。CAD中的轮子只是被动占位，没有驱动底盘。
3. 双管拉杆Ø12、管距180；管轴X139/Y±90，最高Z1140，即伸出箱顶350。导座嵌入箱壳，管前切面X145贴板背。此档用于审形，不拉长到奶龙头顶。
4. 奶龙必须有参考照片的形状：圆头短嘴、大眼、内收脖颈、圆肚子、抱腹手臂、分开的两只脚；不要换回黄色矩形。用 cad/standee/nailong_profile.py 的可修改轮廓及印刷图层。
5. 立牌是一张8 mm厚的KT轮廓板，不是立体雕塑；正脸朝+X，板背X145贴箱面和拉杆。本体高1600…1800，默认1600；按照片比例缩放，默认宽约792，不强压到旧500宽。
6. 最低脚尖离地20 mm，默认总高1620；1800板总高1820。板下段贴箱外侧，不插入箱腔，不叠箱顶，不做人字双板。脚附近间隙需后续按地面条件实测。
7. 暂用两条背面横压条表示固定位置（中心Z920/1080，250×16×30 mm，双管槽），正面不画三条黑带。它们是安装概念，未设计最终夹具/螺钉/承载，不可当作制造图。
8. 印刷图案是预览用零厚度平面及SVG，实体STEP只有轮廓板。不要把眼睛、肚子、手臂做成凸起的实体零件。
9. cad/handle/ 和 cad/standee/ 保留CadQuery源码，更新STEP/STL、真实几何正背面与侧视预览；两处NOTES各十行以内，写外形、拉杆伸出、管距、固定概念、最低脚尖和头顶高度。
10. docs/BOM.md 分外形样机材料和驱动待选件；docs/FUNCTIONS.md 说明手机遥控→ESP32→带编码器的双电机差速，以及速度斜坡、失联停车、急停、倾斜和障碍停车。跟随/语音留后续，不把RSSI当可靠方向。
11. simulation/ 先做参数可改、可复现的运动学和准静态估算：直行、转弯、受控刹停/失联、质量重心、倾覆边界与电机扭矩。假设和未建模项写清楚，勿把计算当实测；现有CAD被动轮和候选驱动轮尺寸须区分。

检查箱子直立、奶龙轮廓比例、板脚接近轮底、背面贴合、零件无穿模。完成本轮模型、清单和仿真后停下，等用户看外形和功能取舍。
