# PRD · 智能改装行李箱 / 流动奶龙

版本 0.1 · 2026-09-30 · 状态：需求评审稿，尚未实物验收。

## 1. 产品定义

把普通行李箱改造成平稳、可手机遥控、能自动跟随主人的智能行李箱。装上可拆奶龙立牌，就变成会跟人、会登场的“流动奶龙”；拆下外观后，仍应保留装物、开箱和手推能力。

用户明确的核心：爆改行李箱、控制平稳、手机遥控、自动跟随，以及奶龙带来的喜剧效果。“神出鬼没”落实为操作者控制下的惊喜登场动作。**自动跟随属于完整产品的必交付能力，遥控成功不等于产品完成。**

本文定义要解决什么、做到什么程度；[PDR](PDR.md)讨论结构与技术是否可行；[BOM](BOM.md)列材料和候选件。下列量化验收中，标为“建议”的数字是供评审的起点，不代表用户已确认或实测达成。

## 2. 用户与使用场景

| 场景 | 用户希望得到的体验 | 产品表现 |
|---|---|---|
| 搬运与布展 | 奶龙自己慢慢走过来，不用一直抱着板 | 手机控制前进、缓转、停靠；松手即发出停车请求 |
| 跟随主人 | 主人走、箱子跟；主人停、箱子停 | 明确绑定一个目标，维持跟距；不误跟其他人 |
| 惊喜登场 | 奶龙从布置好的场景边缘慢慢出现，停住形成笑点 | 按住执行一次短动作，随时能停；可选手动音效 |
| 日常用箱 | 拆掉奶龙后仍是可用的行李箱 | 能开箱取物、手推搬运；裸箱跟随单独验证 |

首轮试验在有人看护的平整室内空地进行。户外、坡道、台阶和拥挤场地不包含在首轮验收中，后续扩展需另列指标。

## 3. 两种形态与功能范围

| 形态 | 外形 | 运行需求 |
|---|---|---|
| 奶龙展示形态 | 竖立箱体在板后；切型板高1.6–1.8 m；脚接近轮底 | 优先平稳、低速和可控停靠，不能用突然加速制造喜剧效果 |
| 裸箱实用形态 | 奶龙与外接撑件可拆；保留箱盖与拉杆使用空间 | 遥控、手推、自动跟随；需单独评审日常步行速度与装载能力 |

当前外形基线：箱身高720×宽470×深290 mm；默认奶龙高1600、宽约792、厚8 mm，最低脚尖离地20 mm，总高1620 mm。1800板等比宽约891、总高1820 mm。20 mm间隙属于审形参数，实物可以根据地面和轮子包络调整。

| ID | 需求 | 优先级 / 交付条件 |
|---|---|---|
| R01 | 起步、转弯、停靠平稳；负载变化后仍可控 | 核心；所有运动模式共享限速、限加速度和停止逻辑 |
| R02 | 手机遥控：连接、使能、前进/转弯、停止、状态反馈 | 核心；工程首轮不开放倒车，补后向探测与验证后再开放 |
| R03 | 自动跟随一个明确绑定的主人/随身目标 | 核心；须测距与辨别相对方向，目标丢失必须停车 |
| R04 | 遥控优先接管自动模式，急停优先于全部动作 | 核心；切换运动模式先停再使能，复位不能自行启动 |
| R05 | 奶龙轮廓可辨识、可拆装、低位固定可靠 | 核心；正常竖箱，板贴箱外侧，不恢复横箱或箱顶叠板 |
| R06 | 奶龙“登场”动作 | 体验项；一次短动作，操作者保持控制；不得覆盖障碍/失联停车 |
| R07 | 行李箱基础用途 | 核心；开箱、储物、提拉和断电手推，避免改成永久封死的配重盒 |
| R08 | 可读的运行状态与故障原因 | 核心；至少显示连接、模式、目标状态、电量、停车原因 |
| R09 | 手动音效、后续更多角色外观 | 可后续增强；不影响核心跟随验收 |

当前不承诺：任意手机无需额外硬件即可提供精确跟随方位、全校园自主导航、自动绕过视线外障碍、载人骑行或无人值守运行。先将“跟准一个主人、稳稳停下”做实。

## 4. 手机端与交互

建议首屏仅包含：设备连接/电量、遥控/跟随/登场模式、启动使能、持续可见的停止按钮、当前故障原因。手机是操作界面，不要求用户配置机器人技术参数。

1. **连接**：选择自己的箱子，显示已连接但保持待机；单一控制端持有控制权。
2. **遥控**：按住摇杆输出速度请求，松手归零；失联也归零。手机停止不替代箱体实体急停。
3. **跟随**：绑定目标 → 确认目标有效/方向合理 → 人工启动 → 跟随；靠太近、目标走太远或丢失则停，不盲追。
4. **接管**：停止或切换遥控优先终止跟随/登场；重新取得目标后由用户明确继续，不能突然补跑。
5. **登场**：建议首次仅执行前进≤1 m、持续≤5 s的一次动作，按住才执行，松开/到点/遇障即停止；距离与时间以先到者为准，不循环、不无人定时触发。
6. **收纳**：断开动力使能，拆奶龙，确认箱盖与手推可用。换装后必须切换到对应速度配置。

## 5. 量化验收建议

下表为待评审目标；几何尺寸来自当前粗模，其余除已注明的计算值外均未验证。试验需记录实际质量、载荷、地面、板高、软件版本和原始日志，不能只交一段成功视频。

| ID | 项目 | 建议目标与测法 |
|---|---|---|
| A01 | 奶龙模式运动边界 | 首轮≤0.30 m/s、加速度≤0.25 m/s²、转弯半径≥1.5 m；记录编码器与IMU曲线，不原地甩尾 |
| A02 | 平稳性 | 空载/建议5 kg载物两档，各10次起停+10次左右缓转；不倒、不擦板脚、不松夹具；建议直行稳态速度误差≤10%，暂用视频测板顶摆幅并在结构评审确定阈值 |
| A03 | 遥控与失联停止 | 有效指令过期200 ms内进入受控停车；0.30 m/s、平地条件建议最坏停距≤0.40 m；20次均记录通过。断电滑行和急停另测，不能套用此停距 |
| A04 | 低速跟随 | 建议目标跟距1.8 m，稳态范围1.5–2.1 m；30 m路线含两次缓转、三次起停，10轮至少9轮完成，稳态90%以上时间处于范围内 |
| A05 | 不误跟与目标丢失 | 插入旁人、遮挡、过期数据与断连各20次；不切换到陌生目标，进入停车且不自行重启；200 ms是目标信息有效期的初始建议，跟随传感器必须能支撑 |
| A06 | 障碍与接管 | 障碍检测覆盖整机扫掠宽度；20次接管/障碍停车无碰撞。触发距离由最坏实测停距加定位/检测余量确定，不能只用名义测距距离 |
| A07 | 奶龙拆装 | 建议1人≤5 min，重复10次后无松动；不用拆电池和重新接动力线；夹具不压坏KT板、不遮传感器 |
| A08 | 实用行李箱 | 建议有效储物空间≥改装前60%；5 kg载物下开合20次、断电手推10 m可用；测试值不足时必须调整结构或明确降级 |
| A09 | 续航 | 建议首轮样机完成30 min混合遥控/跟随/等待；报告各模式时长、里程和电量，不拿待机时长冒充移动续航 |
| A10 | 裸箱日常跟随 | 提出0.8 m/s作为待评审速度目标；必须重新选型并验证制动、稳定性与跟距。当前0.3 m/s粗模/仿真不能据此宣称已实现日常步行随行 |

预算上限、交付日期、手机系统、实际箱型号、载物与续航指标尚未由用户给定。表中的5 kg、30 min、0.8 m/s及允许随身标签都是评审假设；先据此暴露设计问题，评审后再冻结采购规格。

## 6. 实现阶段与产品完成标准

| 阶段 | 交付 | 通过条件 |
|---|---|---|
| M0 外形与方案审查 | CAD、PRD/PDR、BOM、初步仿真 | 另一Agent能复现并提出具体问题；选定实箱和固定路线 |
| M1 稳定遥控工程样机 | 驱动、手机界面、速度闭环、停车与故障状态 | A01–A03/A06相关试验通过；仅表示遥控样机完成 |
| M2 低速跟随 + 奶龙首个闭环 | 目标定位、跟随控制、换装与受控登场 | A04–A07通过；跟随是必做，不以遥控表演代替 |
| M3 实用智能行李箱 | 裸箱装载、开合、手推、续航、日常跟随 | A08–A10经评审冻结后通过，才能宣称“真正好用的智能行李箱” |

当前只交付M0所需资料与计算，M1–M3未实现。需求变化先更新本文，再同步PDR、功能方案、BOM和验收任务；不得把“计划支持”写成“已经具备”。
