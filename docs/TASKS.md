# 任务

## L0 选型 · 做了才算过关

- [ ] 买 26 寸硬壳（优先）或 24 寸。空箱约 4.5–6 kg。
- [ ] 买 / 打 1.6 m 高 × 0.5 m 宽 KT 立牌（连框 < 1.5 kg）。
- [ ] 用缩尺量箱外形，写进 `docs/DIMENSIONS.md` 的 actual 段。

## L1 底盘 · 当前主线

- [ ] 下单 **成品重载遥控底盘**，载重 ≥ 20 kg，见 [CHASSIS.md](CHASSIS.md)。
- [ ] 拆掉箱子原装万向轮。
- [ ] V1：箱子闭上，整只扎在底盘台面上。打不开不管。
- [ ] 空载遥控：前进 / 慢转 / 制动。最高 0.3 m/s。
- [ ] 加 8 kg 配重再走一圈。

## L2 箱+底盘一体

- [ ] 轮组不挡地、不挡壳。
- [ ] 人推装箱装配重走 20 m，箱不移位。

## L3 立牌

- [ ] 三道紧缩器带把 1.6 m 板绑在箱顶，底边偏后 40 mm。
- [ ] 静止侧推 2 N，倾斜 < 5°，松手回正。

## L4 稳 + 不倒

- [ ] PWM 斜率 2 秒爬到定速。
- [ ] 禁止原地甩尾。
- [ ] MPU6050 贴板背 700 mm，>8° 急停。

## L5 跟随 / 语音

- [ ] 不开。

## V2（全部 L4 过了再写）

底盘避开钥匙和拉杆，箱盖能开。
