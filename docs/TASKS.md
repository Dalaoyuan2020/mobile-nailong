# 当前任务 · 智能改装行李箱

产品目标与验收见[PRD](PRD.md)，设计缺口见[PDR](PDR.md)。本表取代旧横放任务；自动跟随是必交付功能。

## M0 方案与交接

- [x] 竖箱与1.6–1.8 m奶龙切型粗模、拉杆与固定占位
- [x] STEP/STL、正背面与侧视、几何验证
- [x] 初步运动/稳定性计算、24项断言与交互估算
- [x] PRD、PDR、BOM、功能路线和[审查入口](REVIEW_HANDOFF.md)
- [ ] 另一Agent独立审查并关闭关键问题
- [ ] 实测箱型号、重量、轮接地点、储物/开箱空间；冻结实际参数

## M1 稳定遥控工程样机

- [ ] 完成轮座、加强件、下部承托与夹具详图/验证
- [ ] 选电机、驱动、电源并做架空旋向/编码器/限流验证
- [ ] 手机界面、车端轮速闭环与唯一控制权
- [ ] 受控停车、断连、近障、倾斜、实体急停和复位行为
- [ ] 假负载低速起停、缓转、电流/温升与停车距离记录

## M2 低速跟随与奶龙闭环

- [ ] 冻结随身标签是否可接受、定位路线与成本
- [ ] 实测目标ID、距离、方向、刷新率、延迟、遮挡与误跟
- [ ] 跟随控制共用运动限幅/停止链；目标丢失和遥控接管验收
- [ ] 装板复验、可拆换装和受控短距登场

## M3 实用智能行李箱

- [ ] 评审裸箱0.8 m/s建议目标，重选必要的传动与制动参数
- [ ] 冻结并验证载物、储物空间、开合、提拉、断电手推与续航
- [ ] 分别验收奶龙/裸箱模式；发布实测日志与能力边界
- [ ] 可选手动音效、后向探测及人工倒车
