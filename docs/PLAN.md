# PLAN · 移动奶龙

锁定日：2026-09-29

## 定义

行李箱 = 配重 + 载重小车。
奶龙立牌 = 绑在箱子**上面**。
箱子可以移动、可以遥控。

不是：胶贴贴片、人字撑、把板插进箱里、全校园 SLAM。

## 解决什么

1.7 m 立牌搬一次就烦，静止打卡会梗死。人推着走出戏。移动奶龙把「搬板」变成「板自己来」。

## 形态

```
侧视，行进方向 →

         奶龙头
          |
          |  KT 立牌 ~1500 mm（箱顶算起）
          |
     +----+----+
     | 8eba平箱 |
     | 配重     |
    ●          ●     前从动万向轮
    ●          ●     后驱动减速轮
```

- 24 寸或 26 寸硬壳。优先 26 寸（脚印更大）。
- 箱子躺在最大面上。拉杆收起或拆掉。
- 原装万向轮拆掉，换一块带电机的底盘板，用原轮螺丝孔或拐带筋在箱底。
- 立牌用紧缩器带 / 扎带 / 魔术贴跨过箱面绑死，绑点靠箱面中心偏后。

## 优先级

1. 人推装箱的板走一圈不倒
2. 遥控慢走、慢转、不摔板
3. IMU 倾角急停
4. 语音（靠近笑一声）
5. 跟随主人手机 BLE

## 技术主轴

防倾 > 跟随 > 语音。
不做视觉跟人、不做课表自主出巢、不做大模型控车。

## 能卖的东西

通用「立牌行李箱底盘」。奶龙只是演示皮肤。
