# 电控

> 历史草案：下文的 BLE RSSI 跟随和倾斜后退不用于当前方案。当前实现路线见 [FUNCTIONS.md](FUNCTIONS.md)，选型见 [BOM.md](BOM.md)；倾斜或失联应停机，不自动后退。

建模不依赖这一页。装配时用。

- ESP32
- 双路驱动 + 两只减速电机（后轮）
- MPU6050 贴在立牌背面中高，不是贴在箱上
- 超声 × 3：箱前缘中、左前、右前
- DFPlayer + 喇叭
- 电机电源串急停
- 手机 BLE 摇杆；跟随 = 跟主人手机 RSSI

PWM 斜率：摇杆打满也要 2 秒才到 0.30 m/s。禁止原地甩尾。
俠仰/横滚 > 8° 持续 200 ms → 停转并后退。
