# 材料与硬件清单 · 竖箱奶龙

先用 A 组核对外形和固定，再按仿真与实测选 B 组。当前仓库有外观 CAD 和普通箱轮，没有驱动底盘、电机装配或控制固件；“CAD 已有”不代表实物已备齐。价格、库存、实际承载均待询价，不沿用历史横箱预算。
