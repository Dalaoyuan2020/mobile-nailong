# 24 / 26 寸待机尺寸

> 历史横放方案：当前模型为高 720、宽 470、深 290 mm 的竖立箱体，尺寸与轮位以 [当前 prompt](PROMPT_STAND_HANDLE.md) 为准；下文保留旧设计记录。

市面硬壳外径不统一。建模先用这两档。买到真箱之后用实测覆盖 `case.actual`。

坐标：箱子躺平，最大面贴地。X 前进，Y 左右，Z 向上。

## 24 寸

| | mm |
|---|---|
| 脚印 X（长） | 660 |
| 脚印 Y（宽） | 430 |
| 壳厚 Z | 270 |
| 轮后台面高（含 50mm 底盘） | 320 |

## 26 寸（优先）

| | mm |
|---|---|
| 脚印 X | 720 |
| 脚印 Y | 470 |
| 壳厚 Z | 290 |
| 轮后台面高 | 340 |

## 立牌

| | mm |
|---|---|
| 板高（从箱顶算） | 1500 |
| 板宽 | 500 |
| 板厚 | 8 |
| 绑带宽 | 40 |
| 绑带道数 | 3（距箱顶 80 / 400 / 800） |
| 板底超出箱后缘 | 0（端面落在箱面内，偏后 40mm） |

地面到龙头：24 寸 ≈ 1820 mm；26 寸 ≈ 1840 mm。等高探头用这个高度，不要再加高板。

## 轮距

| | 24 | 26 |
|---|---|---|
| 左右轮距 | 360 | 400 |
| 前后轴距 | 480 | 540 |
| 轮径 | 50 | 50 |

## 配重

箱内均布贴底 8 kg（建模用 8 个 1kg 块）。不放箱盖里。

## 倾覆检查（建模时算一下）

静止侧向：`g * (Y/2) > a_lat * h_cog`

待机：整机重心高 ≤ 450 mm。板轻、箱沉。
设计加速 ≤ 0.25 m/s²，设计速度 ≤ 0.30 m/s。
