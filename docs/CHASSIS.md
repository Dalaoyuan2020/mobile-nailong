# L1 底盘方案

## 决定：V1 买成品，不自研车架

原因：要先验证「20 kg + 1.6 m 板遥控不倒」。自铺车架要花一周对中轮距和减速比，不值。

V1 做法：原装万向轮拆掉 → 箱子闭死 → 整只箱子扎在成品底盘台面上。
盖子打不开 = 接受。

## 买什么

搜索词：`铝合金重载底盘 20kg 四驱 遥控`

待机标：

| 项 | 要 |
|---|---|
| 额定载重 | ≥ 20 kg（我们整机约 17–22 kg） |
| 台面 | ≥ 500 × 350 mm，能承 26 寸躺箱 |
| 驱动 | 差速两轮或四驱都行，不要麦轮 |
| 遥控 | 自带 2.4G 即可，后面再换 ESP32 |
| 速度 | 能限到 0.3 m/s；太快的要能改参 |
| 价格 | **250–450** 

现货里见过「铝合金重载 20 公斤四驱可编程平台 ≈ 395」。按这一档买。

不买：果园履带运输车（2000+）、工厂平车（万级）、电赛 4WD 亚克力板（载不动 20 kg）。

## 备选（没有 20kg 成品时）

自拼：铝板 400×600×5 + 两只 520 减速电机 + 高流驱动 + 两只 4 寸万向轮 + 12V 5Ah。
零件约 **180–280**。调速和对轮要多两天。

## 遥控怎么稳

成品遥控往往太敏。上板之前先用胶带把摇杆行程限到一半，或换 ESP32 做 2 秒 PWM 斜率。
转弯只用差速，两轮不准反转。
板一绑上就把 IMU 接上，超 8° 断电机电。
