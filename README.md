# 移动奶龙 / Mobile Nailong

一只 26 寸行李箱躺平，底下装电动底盘，箱顶绑一块 **1.6 m 全身奶龙立牌**。
手机遥控它走，有人靠近它就「爆笑」，最后能跟着主人走。

> 一句话：**立牌自己会走、会笑、不会倒。**

参赛：SheNicest × STACK ANYWAY「硬件进化论·观点跃迁」消费硬件创作赛（旧物觉醒方向）
截止 **2026-10-13 24:00** · 评分 完成度 40% / 创意 30% / 场景 30%

## 解决什么

1.6 m 立牌搬一次就烦，放着不动没人看，人推着走又出戏。
移动奶龙把「搬板」变成「板自己来」，还会跟路过的人互动。
奶龙只是演示皮肤，底下这套「会走的立牌底座」换张画就能给任何活动用。
