# 26 寸箱壳首版（mm；ABS 深灰）
外形 720×470×290，X ±360 / Y ±235 / Z 0…290；外 R20、内 R17、基础壁厚 3。
分型 Z=170；底壳高 170、箱盖高 120；本轮仅两片箱壳，合装 STEP 保留独立实体。
四个 60×60 轮平台齐平 Z=0；孔 XY=(-270,-200),(-270,200),(270,-200),(270,200)，M6 默认 Ø6.6 光孔。
三条顶槽 X=-80/0/80，沿 Y 长 400、宽 40、深 2；内侧补料使槽底仍厚 3。
配重净空 100×50×40×8，中心 X=-210/-70/70/210、Y=±85，平底 Z=3，定位框高 2；不含配重块。
前 +X 端 Ø18×3，Y=-120/0/120、Z=40；后 -X 端拉杆凹槽 160×50×4、中心 Z=120。
后内壁平台 80(Y)×50(Z)，中心 Z=55、安装面 X=-354；无电盒、拉杆、锁扣或铰链。
复现：`python -m pip install -r cad/case26/requirements.txt` 后 `python cad/case26/case26.py`；预览运行同目录 `render_preview.py`。
`case26.stl` 仅合装看形；打印用底壳 STL 与 `case26_lid_print.stl`（盖翻转落地）；需适配 720×470 大幅面设备，尚未实打/承载验证；先评外形。
